Algorithm Execution Logic
  1. Booking Insertion: Checks if ConfirmedLinkedList.size < capacity. If true, appends node to Linked List ($O(N)$ insertion). If full, enqueues passenger into WaitingQueue ($O(1)$ enqueue).
  2. Cancellation & Automatic Promotion: Searches confirmed linked list for matching PNR ($O(N)$ node traversal). If found, removes the node and instantly dequeues head passenger from WaitingQueue ($O(1)$ FIFO dequeue) to promote them to Confirmed status.
